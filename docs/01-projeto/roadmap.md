# Roadmap

Marcos estimados, sujeitos à revisão conforme validação do produto:

| Versão | Objetivo |
|---|---|
| 0.1.0 | Fundação Django, configuração inicial PostgreSQL, documentação, apps e API base |
| 0.1.1 | MySQL local/principal, verificação da conexão e migrations, branding e design system inicial |
| 0.2.0 | Autenticação, cadastro, perfil pessoal e sessão segura |
| 0.3.0 | Catálogo, prestadores, anúncios e Home do marketplace |
| 0.4.0 | Busca, localização e perfil profissional |
| 0.5.0 | Solicitações e contratação |
| 0.6.0 | Chat, avaliações e notificações básicas |
| 0.7.0 | BICO Gestão, moderação, atendimento e indicadores |
| 0.8.0 | PWA, integração e estabilização |

Flutter Android/iOS será planejado posteriormente e consumirá a API. Pagamentos e comércio de produtos permanecem fora do Alpha inicial.
