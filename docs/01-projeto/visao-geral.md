# Visão geral

**BICO** conecta pessoas que precisam de serviços a profissionais independentes. O mercado inicial é Campinas-SP; a interface é em português brasileiro e o código utiliza convenções em inglês.

O produto será um monólito modular Django com site/PWA, API compartilhada e, em fase futura, BICO Gestão e aplicativo Flutter. A prioridade inicial é validar a descoberta e contratação de serviços com uma experiência acessível, próxima e confiável.

Não fazem parte do Alpha inicial produtos físicos, estoque, logística, pagamentos ou microsserviços.
