# Diretrizes de interface

Interface pública em português brasileiro, responsiva e clara. Priorizar hierarquia visual, linguagem simples, acessibilidade por teclado, foco visível e feedback honesto. Navegação pública não deve exigir conta; ações privadas podem encaminhar para autenticação quando implementada.

Referências anexadas mostram Home, login/cadastro, anúncio e perfil. Nesta fundação, somente uma Home mínima foi criada para confirmar a execução; imagens não autorizam apresentar preços, avaliações ou selos fictícios.
