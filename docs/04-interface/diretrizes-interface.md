# Diretrizes de interface

Interface pública em português brasileiro, responsiva e clara. Priorizar hierarquia visual, linguagem simples, acessibilidade por teclado, foco visível e feedback honesto. Navegação pública não exige conta; ações privadas encaminham para autenticação quando necessário.

Referências anexadas mostram Home, login/cadastro, anúncio e perfil. A Home, autenticação, detalhe público de anúncio com galeria e perfil público com portfólio estão implementados. Conteúdo de demonstração deve estar identificado; não apresentar preços, avaliações, selos, distância ou disponibilidade inventados como informação real. A composição e os estilos reutilizáveis estão em [design-system.md](design-system.md).
