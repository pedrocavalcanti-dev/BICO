# Identidade visual

- Laranja principal aproximado: `#FF5A1F`.
- Fundo branco, texto grafite e títulos azul-acinzentados escuros.
- Tipografia de sistema com formas modernas; sem dependência de fonte externa.
- Botões arredondados, contraste suficiente e foco visível.
- Fotos reais e informações de reputação somente quando dados reais estiverem disponíveis.

A Home inicial aplica esses princípios de forma deliberadamente simples; a identidade deverá ser refinada com os arquivos de design quando forem adicionados ao repositório.
