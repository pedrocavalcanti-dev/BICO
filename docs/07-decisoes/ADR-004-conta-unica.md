# ADR-004 — Conta única para cliente e prestador

- **Estado:** aceito.
- **Contexto:** uma pessoa pode contratar e oferecer serviços.
- **Decisão:** um `accounts.User`; perfil profissional será relação opcional futura. O papel profissional não implica privilégio administrativo.
- **Consequência:** alternância de modo não duplica identidade; autorização operacional permanece separada.
