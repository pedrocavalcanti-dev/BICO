# Política de acesso

Visitantes poderão consultar conteúdo público. Ações que persistem identidade exigirão autenticação. Usuários acessam somente seus próprios dados privados; prestadores acessam solicitações destinadas a eles; conversas futuras ficam restritas aos participantes.

Django Admin é técnico e restrito a `is_staff`/permissões administrativas. Ativar perfil profissional não concede privilégio. BICO Gestão terá papéis operacionais próprios futuramente, com menor privilégio e auditoria. Regras ainda não implementadas não devem ser tratadas como garantidas.
