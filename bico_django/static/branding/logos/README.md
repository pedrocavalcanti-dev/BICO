# Logos e marcas

Os arquivos BICO desta pasta são os assets de marca fornecidos para o projeto. Não editar, recriar ou aplicar fundos às logos.

`google-g-icon.png` é o símbolo oficial do Google baixado da página de identidade do Google Sign-In: <https://developers.google.com/identity/branding-guidelines>. Ele aparece apenas ao lado de um botão desabilitado, com o estado “Em breve”; a BICO não oferece autenticação Google nesta versão. Manter a indicação de estado e as regras de marca do Google se a integração for implementada futuramente.
