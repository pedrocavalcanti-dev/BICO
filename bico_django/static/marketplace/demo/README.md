# Imagens demonstrativas do marketplace

As imagens desta pasta foram geradas especificamente para a demonstração visual da BICO. Não representam clientes, prestadores, trabalhos contratados ou avaliações reais. Os três retratos também são personagens gerados, usados somente nos primeiros perfis do seed demonstrativo.

Os arquivos foram convertidos para WebP e limitados a 1280 px no maior lado. O seed `seed_bico_demo` copia imagens para `MEDIA_ROOT` apenas em campos vazios de categorias, perfis/anúncios `is_demo=True` e banners demonstrativos. A repetição do comando não substitui arquivos já escolhidos. Uploads reais permanecem em mídia gerenciada e não devem ser colocados em `static/`.
